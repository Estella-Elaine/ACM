#### **一、**  **位运算**
基本的位运算：共 6  种，分别为按位与、按位或、按位异或、按位取反、左移和右移。

##### **异或( ^ )：**
a ^ a = 0 , a ^ 0 = a 
交换a , b ：  a = a ^ b , b = a ^ b , a = a ^ b
**快速寻找数组中出现奇数次的数**（其他都为偶数）
a是奇数 a ^ 1 = a - 1 ,因为消除零              a是偶数 a ^ 1 = a + 1
x ^ ( 1 << n ) 把 x 的第 i 位翻转
**a xor (a xor b) = (a xor a) xor b = 0 xor b = b**

##### **取反( ~ )：**
它的作用是把 𝑛𝑢𝑚  的**二进制补码**中的 0  和 1  全部取反（0  变为 1 ，1  变为 0 ）。**有符号整数的符号位在** **~** **运算中同样会取反**。

**原码：最高位表示符号：0 为正，1 为负，其余位表示数值的绝对值。
补码：** 在二进制表示下，正数和 0 的补码为其本身，负数的补码是将其对应正数**按位取反**后+1。
**反码：正数：反码 = 原码       负数：符号位保持为 1，其余位按位取反（0→1, 1→0）。

**左移：num << i 表示将 𝑛𝑢𝑚  的二进制表示向左移动 𝑖  位所得的值。
右移：num >> i 表示将 𝑛𝑢𝑚  的二进制表示向右移动 𝑖  位所得的值。
$$
\begin{aligned}
5 &= (00000101)_2 \\
\sim 5 &= (11111010)_2 = -6 \\
-5\text{ 的补码} &= (11111011)_2 \\
\sim(-5) &= (00000100)_2 = 4
\end{aligned}
$$

###### 区间筛：
场景：求区间 [L,R][L,R] 内的素数，其中 RR 很大（如 10121012），但区间长度 R−LR−L 较小（如 106106）。  
核心思想：[L,R][L,R] 内的合数必有一个不超过 RR​ 的质因子。
1. 先预处理出 1∼R1∼R​ 内的所有素数。
2. 用这些素数去筛掉区间 [L,R][L,R] 内的倍数。
```cpp
typedef long long ll;
void segmented_sieve(ll L, ll R) {
    vector<bool> is_p(R - L + 1, true);
    if (L == 1) is_p[0] = false;
    
    for (ll i = 2; i * i <= R; i++) {
        if (isPrime(i)) { // 使用预处理的素数
            // 找到大于等于L的第一个i的倍数
            for (ll j = max(i * i, (L + i - 1) / i * i); j <= R; j += i)
                is_p[j - L] = false;
        }
    }
}
```

#### **四、**  **同余运算与剩余系**
##### 扩展中国剩余定理 （EXCRT）
**应用场景**：求解一元线性同余方程组（即韩信点兵问题）。  
x≡a1(modm1)x≡a1​(modm1​)  
x≡a2(modm2)x≡a2​(modm2​)   ...  
**前提条件（极苛刻）**：所有的模数 m1,m2…mnm1​,m2​…mn​ 必须**两两互质**！
它的思想是通过 ExGCD，把两个方程合并成一个方程，极其精妙：
```cpp
// 扩展中国剩余定理 (EXCRT)
// 解决模数 m[i] 不互质的情况！
// 返回值：方程组的最小非负整数解，如果无解返回 -1
ll EXCRT(int n, ll a[], ll m[]) {
    ll ans = a[1], M = m[1]; // 初始化：先满足第一个方程
    
    for (int i = 2; i <= n; i++) {
        // 当前要解的合并方程：ans + k * M ≡ a[i] (mod m[i])
        // 转化为 ExGCD 形式：k * M + y * m[i] = a[i] - ans
        ll A = M, B = m[i], C = (a[i] - ans % B + B) % B; // C 是常数项，防止负数
        ll x, y;
        ll d = exgcd(A, B, x, y);
        
        // 如果 C 不能被 gcd(A, B) 整除，根据裴蜀定理，方程无解！
        if (C % d != 0) return -1;
        
        // 算出一组特解 x
        ll bg = B / d; // 模数缩放
        x = (ll)((__int128)x * (C / d) % bg); 
        x = (x % bg + bg) % bg; // 保证 x 是正数
        
        // 更新总答案和总模数
        ans += x * M;
        M *= bg;        // 更新总模数为 lcm(M, m[i])
        ans = (ans % M + M) % M;
    }
    return ans;
}
```

#### **五、**  **乘法逆元**

定义：如果 $a⋅x≡1(mod  m)a⋅x≡1(mod m)$，我们就称 x 是 a 在 模 m 下的乘法逆元，记作 $a−1$。  
**作用：** 在 模m 意义下，**除以一个数等于乘以这个数的逆元**。  
$a/b(mod m)=(a⋅b−1)(mod m)$

三个板子：
##### 方法 A：费马小定理（最常用）
- 前提条件：m 必须是质数，且 a 不是 m 的倍数。
- 原理：am−2≡a−1(mod m)。
- 实现：使用快速幂。
```cpp
typedef long long ll;
ll fast_pow(ll a, ll b, ll m) {
    ll res = 1;
    a %= m;
    while (b > 0) {
        if (b & 1) res = res * a % m;
        a = a * a % m;
        b >>= 1;
    }
    return res;
}

// 求 a 在模 m 下的逆元
ll inv(ll a, ll m) {
    return fast_pow(a, m - 2, m);
}
```

##### 方法 B：扩展欧几里得算法 (exGCD)
- 前提条件：a 与 m 互质（gcd⁡(a,m)=1），m 不一定是质数。
- 原理：解方程 ax+my=1，求出的 x 即为逆元。
```cpp
ll exgcd(ll a, ll b, ll &x, ll &y) {
    if (b == 0) {
        x = 1, y = 0;
        return a;
    }
    ll d = exgcd(b, a % b, y, x);
    y -= (a / b) * x;
    return d;
}

ll inv_exgcd(ll a, ll m) {
    ll x, y;
    ll d = exgcd(a, m, x, y);
    if (d != 1) return -1; // 无逆元
    return (x % m + m) % m; // 确保结果为正数
}
```

##### 方法 C：线性求逆元（求 1~n 所有数的逆元）
- 场景：当需要频繁用到 1∼N1∼N 范围内的所有逆元（如组合数计算）。

```cpp
ll inv[MAXN];
void get_all_inv(int n, int m) {
```

```cpp
const int MOD = 1e9 + 7;
const int MAXN = 100005;
ll fact[MAXN], invFact[MAXN];

ll fast_pow(ll a, ll b) { /* 见上文 */ }

// 预处理阶乘和阶乘的逆元
void init() {
    fact[0] = 1;
    for (int i = 1; i < MAXN; i++) fact[i] = fact[i - 1] * i % MOD;
    
    // 阶乘逆元的推导：(n!)的逆元 = ((n+1)!)的逆元 * (n+1)
    invFact[MAXN - 1] = fast_pow(fact[MAXN - 1], MOD - 2);
    for (int i = MAXN - 2; i >= 0; i--) {
        invFact[i] = invFact[i + 1] * (i + 1) % MOD;
    }
}

ll nCr(int n, int r) {
    if (r < 0 || r > n) return 0;
    // 公式：n! / (r! * (n-r)!)
    return fact[n] * invFact[r] % MOD * invFact[n - r] % MOD;
}
```
