###### Eg1:
```cpp
int func ( int n )
{   int i = 0, sum = 0;
    while ( sum < n )  sum += ++i;
    return i;
}
```
循环条件是 `sum < n`，每次 `sum` 增加 `i`。即 $1+2+⋯+i<n1+2+⋯+i<n$，求和公式为 $i(i+1)2<n2i(i+1)​<n$，这意味着 $i2≈2n$，所以 $i≈n​$，复杂度为 $O(n)$，即 $O(n1/2)$。


根据对数性质，$log⁡N2=2log⁡NlogN2=2logN$。因此，$Nlog⁡N2=2Nlog⁡NNlogN2=2NlogN$。在算法分析中，常数系数（如这里的2）不影响增长阶数，所以两者的增长速度是同一数量级的，均为 $O(Nlog⁡N)$。


算法复杂度：$O(1)$
```cpp
int m = 100, n = 200;
while (n > 0) {
	if (m > 100)  m -= 10, n--;
	else  m++;
}
```
1. **初始状态**：`m = 100`, `n = 200`。
2. **第一次循环**：因为 `m` 等于 100（不大于 100），执行 `else` 分支，`m` 变为 101。此时 `n` 依然是 200。
3. **第二次循环**：因为 `m` 等于 101（大于 100），执行 `if` 分支，`m` 减去 10 变为 91，同时 `n` 减 1 变为 199。
4. **后续循环**：现在 `m = 91`，它需要连续执行 **10次** `else` 分支（`m++`）才能重新大于 100。每当 `m` 再次大于 100 时，它会执行一次 `if` 分支让 `n` 减 1，然后 `m` 又掉回 91 附近。
5. **总结规律**：为了让 `n` 减少 1，程序必须先让 `m` 从 91 增加到 101。这意味着每减少一次 `n`，循环大约要执行 11 次左右。
- 这里的 **nn 和 mm 都是具体的常数**，而不是变量（虽然代码里写的是 `int m=100, n=200`，但在算法分析的语境下，如果题目没有说明 nn 是输入规模，它们就被视为常数）。
- 无论循环执行多少次，它最终都会在一个确定的、有限的步数内停止（大约 200×11=2200200×11=2200 次左右）。
##### ！注意：在很多数据结构的练习题中，如果给出了变量的具体初始值且循环次数固定，通常考查的就是“常数阶”这个概念。
