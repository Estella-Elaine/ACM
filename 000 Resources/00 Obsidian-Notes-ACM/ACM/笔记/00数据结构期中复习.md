### 02 链表
#### 考点一：链表与数组（顺序表）的终极对比（🔴 必考选择/简答）
老师极其喜欢考这两者的优缺点对比。你需要像条件反射一样记住以下结论：
1. **内存分配**：
    - **数组**：静态分配（或一次性动态分配），内存必须**连续**。容易造成内存浪费或溢出。
    - **链表**：动态分配（`malloc`），内存是**离散**的。用多少申请多少，不浪费。
2. **时间复杂度对比（重中之重）**：
    - **按位置查找（找第 i 个元素）**：数组 O(1)（随机存取）；链表 O(N)（只能从头数）。
    - **按值查找（找值为 x 的元素）**：无序情况下两者都是 O(N)。
    - **插入/删除操作**：
        - 数组 O(N)：因为要搬移大量元素。
        - 链表 O(1)：**注意陷阱！**前提是“已经给出了插入/删除位置的指针”。如果是“在第 i 个位置插入”，那依然是 O(N)，因为找位置要 O(N)，但修改指针只要 O(1)。

#### 考点三：“带头结点” vs “不带头结点”（🟡 易错判断/填空）
这是课本里最喜欢玩的文字游戏。
- **不带头结点**（你之前写的代码就是这种）：`head` 指针直接指向第一个存放实际数据的节点。
- **带头结点（Dummy Head）**：链表永远有一个没有任何意义的头节点（无论链表空不空），`head->next` 才是第一个有数据的节点。
**常考考法（如何判断链表为空）：**
- 如果**不带头结点**，判空条件是：`head == NULL`
- 如果**带头结点**，判空条件是：`head->next == NULL`

#### 考点四：头插法与尾插法的特性（🟡 必考选择/填空）
老师会给你一串输入序列，问你用这两种方法建立链表后，结果是什么样的。
1. **头插法（Head Insertion）**：
    - 每次把新节点插在最前面。
    - **特性：逆序！** 如果输入数据是 `1, 2, 3`，建好的链表是 `3 -> 2 -> 1`。
    - 考试常用于实现链表的**就地逆置**（不用额外空间把链表反转）。
2. **尾插法（Tail Insertion）**：
    - 每次把新节点接在最后面。
    - **特性：顺序！** 输入 `1, 2, 3`，建好的就是 `1 -> 2 -> 3`。
    - **考点：必须额外维护一个 `tail` 尾指针**，否则每次插入都要从头遍历找尾巴，时间复杂度会从 O(1)O(1)O(1) 退化成 O(N)O(N)O(N)。

#### 考点五：特殊链表的判空与遍历边界（🔵 填空题）
除了单向链表，课内通常还会学循环链表和双向链表。考试喜欢考它们的**终止条件**：
1. **单向循环链表**：
    - 尾节点不再指向 `NULL`，而是指回 `head`。
    - **遍历结束的条件**：不再是 `while(p != NULL)`，而是变成了 **`while(p->next != head)`** 或 `while(p != head)`。
2. **双向链表（Doubly Linked List）的插入**：
    - 填空题最爱考双向链表的插入，一共 4 句话，非常容易乱：
    - 假设在 `p` 之后插入 `s`：
```cpp
	s->next = p->next; 
	if(p->next != NULL) p->next->prev = s; // 这一步最容易忘！ 
	s->prev = p; 
	p->next = s;
```


**链表逆置：头插法 / 链表重连**
**单链表不一定要有头节点，但是一定要有头指针**
头节点(Dummy Head Node)：用于代码便捷
头指针(Head Pointer)：保存地址的变量
